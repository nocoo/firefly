# Journal font assets

Locally hosted Latin WOFF2 subsets, shared with the lizheng.me / lizheng.dev design. CJK text uses system fonts. No third-party font requests are needed.

| Asset | Source | License |
| --- | --- | --- |
| space-grotesk.woff2 | Fontsource / Space Grotesk, variable 300–700 | space-grotesk-LICENSE.txt |
| source-sans-3.woff2 | Fontsource / Source Sans 3, variable 200–900 | source-sans-3-LICENSE.txt |
| geist-mono.woff2 | Fontsource / Geist Mono, variable 100–900 | geist-mono-LICENSE.txt |
| silkscreen.woff2 | Fontsource / Silkscreen, regular 400 | silkscreen-LICENSE.txt |

The original font binaries and OFL license notices are retained. Public CSS declares unique `Journal *` family names so loading the journal does not change admin typography.
