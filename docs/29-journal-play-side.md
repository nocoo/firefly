# Journal：三个访问面的共同主题

2026-09-05。Firefly 的公开博客 `lizheng.blog` 与 `lizheng.me` / `lizheng.dev` 共用视觉语言，保留博客作为长文阅读空间的特点。

## 范围和隔离

- 公开页面：主页、文章、分类、标签、归档、搜索、分页和 404。
- 新样式集中在 `src/app/(blog)/journal.css`，全部以 `.blog-shell.journal-theme` 为作用域。字体使用独立的 `Journal *` 家族名。
- 后台路由、管理组件、编辑器预览、共享 ArticleBody、根布局、共享 CSS 和主题组件均未修改。公开主题的浏览器地址栏颜色在离开时还原。
- API、数据库、Worker、认证、文章内容、RSS、sitemap、llms.txt、结构化数据与部署配置不变。

## 视觉与阅读

| 元素 | 约定 |
| --- | --- |
| 品牌 | 橙色四方标记、Space Grotesk 字标、公开页面专用 favicon |
| 明亮主题 | 纸张灰绿 `#f0f0e9`，深橄榄文字，陶土橙色强调 |
| 深色主题 | 深绿 `#1e2824`，温暖浅色正文 |
| 页头与侧栏 | 页头仅保留共用字标和访问面导航；侧栏社交链接为单排图标，搜索、分类、标签、归档按组分隔 |
| 首页 | 真实站点题词，原创卡带／像素书插图与橙白收藏球，全部文章统一通栏画廊式大图 |
| 字体 | Space Grotesk、Source Sans 3、Geist Mono、Silkscreen；CJK 使用系统字体 |
| 作者偏好 | 保留现有 serif / classic 正文与标题字体配置 |
| 动画 | 首页 650ms 轻微渐入、抽屉过渡；页脚 7.4s 非线性呼吸灯 |
| 页脚 | 三站链接、RSS、搜索、归档、sitemap、llms.txt；版本号低调显示 |

所有文章卡片采用相同的标题、通栏 3:2 展示框与 `object-fit: contain`，首篇不再单独裁成横幅。常见 3:2 原图完整铺开，宽幅或竖幅保留纸色留白，不拉伸；悬停不放大图片。标题与日期在图上方，摘要与阅读链接在下方。配图右下圆角桌面最大 72px、手机 40px，强化卡带轮廓，其余三角保持小圆角。首图仍优先加载，后续图片保持懒加载。

页面总宽上限 1500px。文章与右侧目录合计上限 936px，目录占 204px；没有目录时正文上限 760px。正文桌面 18px / 1.95，移动端 17px / 1.9。目录在 1280px 以上显示，移动导航在 768px 及以下使用抽屉。

目录使用普通锚点，可直接链接章节。当前章节跟随滚动、快速跳转和反向阅读，使用 `aria-current="location"`；标题滚动偏移根据当前顶栏高度计算。长代码与宽表格局部滚动，页面不横向溢出。

## 可访问性与加载

- 跳到正文、单一页面 h1、键盘焦点样式、抽屉焦点限制和 Escape 关闭。侧栏社交导航在首页、文章和列表页共用，只显示单排图标，不展示 ELSEWHERE 标题。名称保留在屏幕阅读器文本和原生 `title` 中；悬停、键盘聚焦或按下时呈现主题橙色圆形背景，图标反色，过渡为 180ms，减少动态效果时取消过渡。圆形尺寸随侧栏宽度收缩，桌面最大 40px、手机最大 44px。
- 侧栏依次分为社交、搜索、分类、标签、归档，使用一致的留白和细线分组。THE COLLECTION、分类、标签、归档共用 5px 橙色方点、等宽字体、9px 图文间距和 16px 标题下间距；英文装饰标题为 9px，中文功能标题为 11px，保留标题语义，方点对辅助技术隐藏。搜索输入框允许收缩，1100px 及以下隐藏 `/` 快捷键提示，避免挤出边框；桌面快捷键功能保留。
- 归档保留近两年按月、更早按年的分组和计数，默认展示前 12 项。超出时使用原生 `details/summary` 展开或收起，关闭 JavaScript 仍可操作；抽屉的焦点循环包含展开控件，并通过 `checkVisibility` 排除折叠内容，避免焦点落到隐藏链接。
- 抽屉关闭或切换到桌面宽度后，恢复正文交互与页面滚动；React 管理的 main inert 不再由副作用重复还原。
- 原创插图、收藏球和发光点对辅助技术隐藏。收藏球沿用 Play side 的陶土橙／象牙白造型，放在首页卡带旁和页脚跨站链接旁；不增加循环动画或交互，不使用品牌字样。减少动态效果时，取消入场、呼吸和位移动效；正文始终直接由服务端输出。
- 原有文章 metadata、canonical、JSON-LD 和语义链接继续输出。关闭 JavaScript 仍可阅读和通过页脚访问归档、搜索及机器可读内容；搜索页提供原生 GET 表单，手机端无需先打开抽屉即可搜索。
- 字体本地托管，共约 82KB WOFF2，许可证一同提交；不增加运行时依赖。列表大图的 sizes 匹配内容列宽度，首图保留高优先级，其余图片保持懒加载。

## 回归验证

`e2e/bdd/blog-design.spec.ts` 覆盖跨站链接、标题与 canonical、移动抽屉恢复、后台样式隔离、无 JavaScript／减少动态效果、长文目录跳转、宽代码与表格、主题切换与刷新。

`e2e/bdd/archive-navigation.spec.ts` 用项目实际组件与公开样式渲染独立数据，在关闭 JavaScript 的浏览器中验证 0 / 3 / 12 / 20 项、旧年份合并计数、默认上限及键盘展开／收起，不读写数据库。先运行原有无限展开列表，断言收到 21 项而非 12 项失败，再实现原生折叠。另将实际归档组件挂载到真实抽屉中验证展开／收起状态下的 Tab、Shift+Tab 和 Escape；旧版把折叠链接算入焦点循环的实现先失败，再修正可见性判断。

执行方式：

```sh
bun run lint
bun run test:coverage
bun run test:e2e:browser
```

完整浏览器测试使用项目现有本地 Worker、D1、R2 和认证替身。新增长文场景明确限制在 `http://localhost:27028` 且要求 `E2E_TEST_RUNNER=true`，不会向日常开发环境或线上写入测试文章。旧套件中的缺少种子数据跳过项仍按原规则报告。
