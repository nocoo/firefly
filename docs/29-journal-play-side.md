# Journal：三个访问面的共同主题

2026-09-05。Firefly 的公开博客 `lizheng.blog` 与 `lizheng.me` / `lizheng.dev` 共用视觉语言，保留博客作为长文阅读空间的特点。

## 范围和隔离

- 公开页面：主页、文章、分类、标签、归档、搜索、分页和 404。
- 新样式集中在 `src/app/(blog)/journal.css`，全部以 `.blog-shell.journal-theme` 为作用域。字体使用独立的 `Journal *` 家族名。
- 后台路由、管理组件、编辑器预览、共享 ArticleBody、根布局、共享 CSS 和主题组件均未修改。公开主题的浏览器地址栏颜色在离开时还原。
- API、数据库、Worker、认证、文章内容、RSS、sitemap、llms.txt、结构化数据与部署配置不变。

## 视觉与阅读

| 元素 | 约定 |
| --- | --- |
| 品牌 | 橙色四方标记、Space Grotesk 字标、公开页面专用 favicon |
| 明亮主题 | 纸张灰绿 `#f0f0e9`，深橄榄文字，陶土橙色强调 |
| 深色主题 | 深绿 `#1e2824`，温暖浅色正文 |
| 首页 | 真实站点题词，原创卡带／像素书插图，首篇大图、其余图文条目 |
| 字体 | Space Grotesk、Source Sans 3、Geist Mono、Silkscreen；CJK 使用系统字体 |
| 作者偏好 | 保留现有 serif / classic 正文与标题字体配置 |
| 动画 | 首页 650ms 轻微渐入、封面小幅缩放、抽屉过渡；页脚 7.4s 非线性呼吸灯 |
| 页脚 | 三站链接、RSS、搜索、归档、sitemap、llms.txt；版本号低调显示 |

页面总宽上限 1500px。文章与右侧目录合计上限 936px，目录占 204px；没有目录时正文上限 760px。正文桌面 18px / 1.95，移动端 17px / 1.9。目录在 1280px 以上显示，移动导航在 768px 及以下使用抽屉。

目录使用普通锚点，可直接链接章节。当前章节跟随滚动、快速跳转和反向阅读，使用 `aria-current="location"`；标题滚动偏移根据当前顶栏高度计算。长代码与宽表格局部滚动，页面不横向溢出。

## 可访问性与加载

- 跳到正文、单一页面 h1、键盘焦点样式、抽屉焦点限制和 Escape 关闭。
- 抽屉关闭或切换到桌面宽度后，恢复正文交互与页面滚动；React 管理的 main inert 不再由副作用重复还原。
- 原创插图和发光点对辅助技术隐藏。减少动态效果时，取消入场、呼吸和位移动效；正文始终直接由服务端输出。
- 原有文章 metadata、canonical、JSON-LD 和语义链接继续输出。关闭 JavaScript 仍可阅读和通过页脚访问归档、搜索及机器可读内容；搜索页提供原生 GET 表单，手机端无需先打开抽屉即可搜索。
- 字体本地托管，共约 82KB WOFF2，许可证一同提交；不增加运行时依赖。列表缩略图的 sizes 匹配实际显示宽度，首图保留高优先级，其余图片保持懒加载。
