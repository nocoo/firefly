# Journal：三个访问面的共同主题

2026-09-05。Firefly 的公开博客 `lizheng.blog` 与 `lizheng.me` / `lizheng.dev` 共用视觉语言，保留博客作为长文阅读空间的特点。

## 范围和隔离

- 公开页面：主页、文章、分类、标签、归档、搜索、分页和 404。
- 新样式集中在 `src/app/(blog)/journal.css`，全部以 `.blog-shell.journal-theme` 为作用域。字体使用独立的 `Journal *` 家族名。
- 后台路由、管理组件、编辑器预览、共享 ArticleBody、根布局、共享 CSS 和主题组件均未修改。公开主题的浏览器地址栏颜色在离开时还原。
- API、数据库、Worker、认证、文章内容、RSS、sitemap、llms.txt、结构化数据与部署配置不变。

## 视觉与阅读

| 元素 | 约定 |
| --- | --- |
| 品牌 | 橙色四方标记、Space Grotesk 字标、公开页面专用 favicon |
| 明亮主题 | 纸张灰绿 `#f0f0e9`，深橄榄文字，陶土橙色强调 |
| 深色主题 | 深绿 `#1e2824`，温暖浅色正文 |
| 页头与侧栏 | 页头仅保留共用字标和访问面导航；侧栏社交链接为单排图标，搜索、分类、标签、归档按组分隔 |
| 首页 | 真实站点题词，六组设备与记录主题的原创矢量装饰，全部文章统一通栏画廊式大图 |
| 字体 | Space Grotesk、Source Sans 3、Geist Mono、Silkscreen；CJK 使用系统字体 |
| 作者偏好 | 保留现有 serif / classic 正文与标题字体配置 |
| 动画 | 首页 650ms 轻微渐入、抽屉过渡；页脚 7.4s 非线性呼吸灯 |
| 页脚 | 三站链接、RSS、搜索、归档、sitemap、llms.txt；版本号低调显示 |

所有文章卡片采用相同的标题、通栏 3:2 展示框与 `object-fit: contain`，首篇不再单独裁成横幅。常见 3:2 原图完整铺开，宽幅或竖幅保留纸色留白，不拉伸；悬停不放大图片。标题与日期在图上方，摘要与阅读链接在下方。配图右下圆角桌面最大 72px、手机 40px，强化卡带轮廓，其余三角保持小圆角。首图仍优先加载，后续图片保持懒加载。

页面总宽上限 1500px。文章与右侧目录合计上限 936px，目录占 204px；没有目录时正文上限 760px。正文桌面 18px / 1.95，移动端 17px / 1.9。目录在 1280px 以上显示，移动导航在 768px 及以下使用抽屉。

目录使用普通锚点，可直接链接章节。当前章节跟随滚动、快速跳转和反向阅读，使用 `aria-current="location"`；标题滚动偏移根据当前顶栏高度计算。长代码与宽表格局部滚动，页面不横向溢出。

## 可访问性与加载

- 跳到正文、单一页面 h1、键盘焦点样式、抽屉焦点限制和 Escape 关闭。侧栏社交导航在首页、文章和列表页共用，只显示单排图标，不展示 ELSEWHERE 标题。名称保留在屏幕阅读器文本和原生 `title` 中；悬停、键盘聚焦或按下时呈现主题橙色圆形背景，图标反色，过渡为 180ms，减少动态效果时取消过渡。圆形尺寸随侧栏宽度收缩，桌面最大 40px、手机最大 44px。
- 侧栏依次分为社交、搜索、分类、标签、归档，使用一致的留白和细线分组。分类、标签、归档共用 5px 橙色方点、等宽字体、9px 图文间距和 16px 标题下间距；中文功能标题为 11px，保留标题语义，方点对辅助技术隐藏。搜索上方不再显示无功能的 THE COLLECTION 标题。搜索输入框允许收缩，1100px 及以下隐藏 `/` 快捷键提示，避免挤出边框；桌面快捷键功能保留。
- 归档保留近两年按月、更早按年的分组和计数，默认展示前 12 项。超出时使用原生 `details/summary` 展开或收起，关闭 JavaScript 仍可操作；抽屉的焦点循环包含展开控件，并通过 `checkVisibility` 排除折叠内容，避免焦点落到隐藏链接。
- 抽屉关闭或切换到桌面宽度后，恢复正文交互与页面滚动；React 管理的 main inert 不再由副作用重复还原。
- 原创插图、收藏球和发光点对辅助技术隐藏。收藏球沿用 Play side 的陶土橙／象牙白造型，放在首页图鉴笔记旁和页脚跨站链接旁；不增加循环动画或交互。减少动态效果时，取消入场、呼吸和位移动效；正文始终直接由服务端输出。
- 原有文章 metadata、canonical、JSON-LD 和语义链接继续输出。关闭 JavaScript 仍可阅读和通过页脚访问归档、搜索及机器可读内容；搜索页提供原生 GET 表单，手机端无需先打开抽屉即可搜索。
- 字体本地托管，共约 82KB WOFF2，许可证一同提交；不增加运行时依赖。列表大图的 sizes 匹配内容列宽度，首图保留高优先级，其余图片保持懒加载。

## 2026-09-06：三个平面的共同框架与六组装饰

me/dev 采用 Journal 的 1500px 页面框架、1060px 内容列、页头字体与细线样式。三个平面的导航顺序都是 Journal / Play / Résumé；640px 及以下改为两行页头，总高 108px，手机端仍可直接访问三站。404 同样具有访问面导航和主题按钮。me/dev 加入与 Firefly 顺序相同的 system → light → dark → system 主题控制，默认自动。me/dev 页脚采用同样的字标、分隔线、等宽小字、地点灯和返回顶部，保留较轻的结构。开发模式下，页头及页脚的跨站链接使用三个本机 HTTPS 预览入口；生产构建使用正式域名。

首页装饰对应 me 的六种设备，由 `JournalKeepsake` 展示：

| 设备 | 博客装饰语义 |
| --- | --- |
| Game Boy | 螺旋装订的 Pokédex 图鉴笔记与橙白收藏球 |
| Nokia 5300 | 保存的短信便笺、键盘收起的滑盖手机与铅笔 |
| Macintosh Plus | 连续打印纸上的早期文稿窗口、软盘与铅笔 |
| iPod Classic | 声音／歌词笔记、播放器与有线耳机 |
| Garmin Edge 540 | 折叠路线手记、码表与铅笔 |
| Honda | 导航路书、正面头盔与钥匙 |

SVG 使用透明背景、柔和阴影与统一的纸张、象牙白、灰绿和陶土色材质，桌面及手机留足边缘空间。公开页面样式继续限定在 `.blog-shell.journal-theme`；装饰对辅助技术隐藏、无指针交互，打印时隐藏，减少动态效果时不播放入场动画。

每个 document 随机选择一次，切换主题、缩放、进入文章／归档再返回都保持同一场景，完整刷新才允许重新选择。选择不写入 localStorage 或 sessionStorage。`JournalIntro` 使用 `connection()` 在请求时选定场景，服务端直接输出该图片，客户端 hydration 沿用同一个初始值，不再先显示图鉴再换图。后续客户端导航直接使用 document 缓存的选择；无 JavaScript 时同样显示完整的随机插图。图片尺寸预留。

图片保存在 `public/journal-keepsakes`，均随 Firefly 自己部署，不依赖旁边仓库运行。原始绘制脚本位于 lizheng.dev 的 `scripts/create-keepsakes.ts`，可用 `bun scripts/create-keepsakes.ts ../firefly/public/journal-keepsakes` 同步生成。没有新增运行时依赖。

新增 `src/lib/journal-keepsake.test.ts` 和 `e2e/bdd/journal-keepsakes.spec.ts`，覆盖六个随机区间、文档生命周期、无效值、真实客户端往返导航、主题切换、320–1920px 访问面导航、首屏 hydration、无 JavaScript 和打印。最终完整隔离回归为 132 项通过，47 项依照旧套件缺少数据的规则跳过，0 失败、0 flaky；新增 9 项检查全部通过、无跳过。既有后台隔离、抽屉键盘导航、长文阅读和主题检查均通过。

L1 共 93 个文件、1,586 项通过；覆盖率为语句 98.44%、分支 95.32%、函数 99.42%、行 98.82%。完整 lint、类型检查与自定义门禁均通过。页头、首页题词区和页脚在 1440px／320px、明暗两种主题下的 axe WCAG 2 A/AA、2.1 AA 检查均为 0 违规；检查等待正常入场动画完成。六组插图逐一目视审查，SVG 外沿透明、阴影完整，手机布局无横向溢出。三个本机 HTTPS 入口已实测相互导航，1440px 下 dev 与 blog 的内容列均为 1060px（浏览器亚像素取整差异小于 0.02px）。
